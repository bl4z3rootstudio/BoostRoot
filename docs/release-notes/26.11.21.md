# BoostRoot 26.11.21

- **"Sadece Boost" artık "Odak Modu (sadece oyun)":** Açıkken Boost'a basınca tüm güç oyuna gider — arka plan uygulamaları Verimlilik moduna alınır, Windows Update/indirmeler duraklar, internet yiyen uygulamalar (torrent, OneDrive, Dropbox) kapanır, DNS temizlenir, zamanlayıcı hassaslaşır. BoostRoot'un kendi özellikleri tamamen kapanır, penceresi küçülür, kendini düşük önceliğe alır ve RAM'ini bırakır. Oyun kapanınca her şey eski haline döner.
- Kapalıyken: aynı Boost + sistem izleme, bilgi kutusu ve diğer ekstralar.
