## BoostRoot 26.11.17 — kasma düzeltmesi / lag fix

- Oyunlarda ve masaüstünde kasmaya yol açan "oyunlara işlemci önceliği" ayarı kaldırıldı ve açılışta otomatik geri alınıyor (Windows varsayılanlarına dönülüyor). / Removed the MMCSS "games priority" tweak that caused game and desktop lag; it is reverted automatically on start.
- Ekran kartı sensörleri (özellikle AMD) en fazla 3 saniyede bir okunuyor; sık okuma sürücüde takılma yapıyordu. / GPU sensors (AMD especially) are read at most every 3 s; frequent polling stalled the driver.
- Oyun sırasında ölçüm 10 saniyede bire indi, ping kontrolü 6 saniyede bire; bilgi kutusu saniyede bir yenileniyor. / Lighter in-game sampling.
- Oyun önceliği "Yüksek" yerine "Normalin üstü": oyun, masaüstünü, fareyi, Discord'u ve sesi artık boğmuyor. / Game priority is Above normal instead of High.
- "Ağ kısıtlamasını kapat" artık sadece ağ ayarını değiştiriyor. / Network throttling tweak only changes the network setting.
