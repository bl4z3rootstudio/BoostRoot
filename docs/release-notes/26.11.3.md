# BoostRoot 26.11.3 — Güncelleme Merkezi

**TR**
- 🔄 **Güncelleme Merkezi:** tek tıkla bütün bilgisayarı tara.
  - **Uygulamalar** (Chrome, Discord, Steam, 7-Zip…): Windows'un resmi winget aracıyla gerçekten en son sürüme güncellenir — tek tek ya da "Hepsini güncelle".
  - **Windows ve sürücüler** (ekran kartı, ağ, ses, Bluetooth, anakart): Windows Update'in resmi sürücüleri listelenir, seçtiklerini indirip yükler. Önizleme gibi gereksiz görünenler "istersen atla" diye işaretlenir; atladıklarını Windows bir daha sormaz.
  - **Ekran kartı sürücüsü:** yaşını gösterir, resmi indirme sayfasını açar.
  - **Gereksiz uygulamalar:** Candy Crush, TikTok, Haberler, Cortana gibi önyüklü uygulamaları tek tıkla kaldır (Xbox ve Store'a asla dokunmaz).
- 🐞 **Hata bildir:** sol menüde; bilgisayar bilgileri hazır bir rapor sayfası açar, göndermek senin elinde.

**EN**
- Update Center: apps via winget, Windows Update incl. drivers (install / skip), GPU driver age, bloatware removal (Xbox/Store protected).
- "Report a bug" button opens a prefilled GitHub issue.
