# Plan 01 — Temel (Core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** BoostRoot'un Windows'a bağımlı olmayan çekirdeğini kurmak: sürüm biçimi, dokunulmaz-ayar koruması, değişiklik günlüğü ve güvenli dosya düzenleme, oyun ayar dosyası biçimleri, profil şeması/doğrulama/öneri, PC puanı ve profil uygulama motoru; hepsi testli ve CI'da.

**Architecture:** `BoostRoot.Core` saf .NET kütüphanesidir (Windows API'si yok); dosya sistemi `IFileSystem` ile soyutlanır, testler bellek içi dosya sistemiyle Linux'ta da çalışır. Ayar biçimleri tek bir `IConfigDocument` arayüzü arkasındadır; profil uygulayıcı yalnızca bu arayüzü, koruyucuyu ve güvenli düzenleyiciyi kullanır.

**Tech Stack:** C# 14, .NET 10, xUnit v3, System.Text.Json (kaynak üretimli, AOT uyumlu), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-12-boostroot-design.md` (bölüm 3, 4, 5, 6.4, 6.16, 8, 11)

## Global Constraints

- Hedef çerçeve `net10.0`; `Nullable` açık; `TreatWarningsAsErrors` açık; `IsAotCompatible` true (yansıma yok, JSON yalnızca kaynak üretimli bağlamla).
- Sürüm biçimi `YY.AY.N`, ilk sürüm `26.11.1`; dosya sürümü `26.11.1.0`.
- Dokunulmazlar (spec 3.1): çözünürlük, pencere modu, tuş atamaları, fare hassasiyeti, nişangah, oyun içi ses/dil. Koruyucu bunlara yazmayı **istisna fırlatarak** reddeder.
- Her yazma: önce yedek, sonra atomik yazma, sonra geri okuyup doğrulama; hata → aynı işlemin tüm değişiklikleri geri alınır.
- Ayar dosyaları yazılırken orijinal satır sonu (CRLF/LF), UTF-8 BOM varlığı, yorumlar ve bilinmeyen satırlar korunur.
- Seviye kimlikleri JSON'da: `quality`, `balanced`, `maxfps`, `competitive`.
- Rekabetçi (`competitive: true`) profillerde hiçbir seviye ölçekleyici (FSR/DLSS) açamaz.
- Lisans başlığı yok; depo kökünde GPL-3.0 `LICENSE` dosyası.
