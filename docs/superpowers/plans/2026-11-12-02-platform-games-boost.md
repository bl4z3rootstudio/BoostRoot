# Plan 02 — Windows katmanı, oyun bulucu, Boost akışı

Spec: 6.3, 6.5, 6.6, 6.16 · Bağımlı: Plan 01 · Uygulama: Native (kısa plan; kullanım limiti nedeniyle ayrıntı testlerde)

**Mimari:** Platformdan bağımsız mantık `BoostRoot.Core` (soyutlamalar, kayıt-defteri değişiklik günlüğü, Boost orkestratörü, geri alma) ve `BoostRoot.Games` (bulucular, eşleştirme, başlatma komutları; IFileSystem + IRegistry ile Linux'ta testli). Gerçek Windows uygulamaları `BoostRoot.Platform.Windows` (net10.0-windows; Linux'ta derlenir, CI Windows'ta test edilir).

## Görevler
1. **Soyutlamalar (Core/Platform):** `IRegistry` (hive: CurrentUser/LocalMachine; GetValue/SetValue/DeleteValue/GetSubKeyNames, değer türü String/DWord/QWord/Binary), `RegistryValue` kaydı, `IProcessManager` (liste, nazik kapat, öldür, askıya al/sürdür, öncelik, başlat), `IPowerPlans` (aktif GUID oku/yaz), `FakeRegistry`/`FakeProcessManager`/`FakePowerPlans` (Testing).
2. **Kayıt defteri değişiklikleri + geri alma (Core/Safety):** `RegistryChanger.Set(operationId, hive, key, name, value)` → önceki değeri (veya yokluğunu) journal `BackupRef` alanına JSON olarak yazar; `UndoService.RevertOperation(opId)` her `Kind` için kayıtlı `IUndoHandler`'ı ters sırada çağırır (`file` → SafeFileEditor, `registry` → RegistryChanger, `powerplan` → PowerPlanChanger). Testler: değer vardı/yoktu → geri alma tam önceki hale; sıra tersten.
3. **Oyun bulucular (Games):** `VdfReader` (Valve metin VDF → iç içe sözlük), `SteamLocator` (HKCU\Software\Valve\Steam\SteamPath → libraryfolders.vdf → appmanifest_*.acf), `EpicLocator` (ProgramData\Epic\EpicGamesLauncher\Data\Manifests\*.item), `RiotLocator` (ProgramData\Riot Games\Metadata\<ürün>.live\<ürün>.live.product_settings.yaml → product_install_full_path; RiotClientInstalls.json → rc_default), `XboxLocator` (her sürücüde \XboxGames\<Ad>), `MinecraftLocator` (%APPDATA%\.minecraft, ModrinthApp\profiles\*, PrismLauncher\instances\*), `RobloxLocator` (%LOCALAPPDATA%\Roblox). Ortak çıktı: `InstalledGame(Source, SourceId, Name, InstallPath, Extra)`. Her bulucu bozuk/eksik dosyada boş liste döner, istisna sızdırmaz.
4. **Katalog + başlatma (Games):** `GameCatalog.Match(profiles, installed)` → profilin `detect` sözlüğüyle (steam=appid, epic=AppName, riot=ürün, xbox=klasör, minecraft=java, roblox=player, exe=dosya adı) eşleşen `CatalogEntry(Profile?, Game?, IsInstalled)`; yüklüler önce, sonra ada göre. `LaunchCommands.For(entry)` → `LaunchCommand(FileName, Arguments, UseShellExecute)`: steam://rungameid/{id}, Epic `com.epicgames.launcher://apps/{ns}%3A{item}%3A{app}?action=launch&silent=true`, Riot `RiotClientServices.exe --launch-product={p} --launch-patchline=live`, diğerleri exe; bilinmiyorsa null ("Ben açarım").
5. **Windows ayarları (Core tanım + Platform uygulama):** `WindowsTweak` kataloğu (Id, TR/EN ad/açıklama, Safe/Advanced, uygulanacak kayıt değerleri listesi). Güvenli: GameDVR kapalı (HKCU\System\GameConfigStore GameDVR_Enabled=0; HKCU\Software\Microsoft\Windows\CurrentVersion\GameDVR AppCaptureEnabled=0), Oyun Modu açık (HKCU\Software\Microsoft\GameBar AutoGameModeEnabled=1), pencereli oyun iyileştirmesi (HKCU\Software\Microsoft\DirectX\UserGpuPreferences DirectXUserGlobalSettings "SwapEffectUpgradeEnable=1;" mevcut değerle birleştirerek), oyun exe'si için GPU tercihi (aynı anahtar, değer adı = exe yolu, "GpuPreference=2;"), güç planı Yüksek Performans (8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c). Gelişmiş: HVCI (HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity Enabled=0), Win11 GlobalTimerResolutionRequests (HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\kernel =1), HAGS (HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers HwSchMode 2/1), saydamlık kapalı. Testler: tweak uygula → beklenen değerler; geri al → önceki değerler; birleştirilen DirectX dizesi diğer alanları korur.
6. **Boost orkestratörü (Core):** `BoostRequest(Profile, Level, CloseList, ApplyWindowsTweaks, GameExePath)`, `IBoostStep { string Id; StepResult Run(BoostContext) }`; sıra: oyun çalışıyor mu kontrolü → oyun ayarları (ProfileApplier) → arka plan kapatma → Windows ayarları → GPU adımı (Plan 04 ekler, yoksa atlanır). Kritik adım (oyun ayarları) başarısızsa önceki adımlar geri alınır. Arka plan kapatmada asla kapatılmayanlar: ses (audiodg), hile korumaları (vgc, vgtray, EasyAntiCheat*, BEService), discord (listede değilse), csrss/explorer/dwm vb., SplitWire/GoodbyeDPI/zapret ailesi. Korumalı oyunda süreç önceliği verilmez. Testler: adım sırası; oyun açıkken `GameRunning` hatası ve hiçbir yazma yok; adım başarısızlığında geri alma; kapatma listesinden korunan süreçlerin elenmesi.
7. **Platform.Windows uygulamaları:** `WindowsRegistry : IRegistry` (Microsoft.Win32.Registry, 64-bit görünüm), `WindowsProcessManager` (CloseMainWindow → 4 sn → Kill; NtSuspendProcess/NtResumeProcess P/Invoke; PriorityClass), `WindowsPowerPlans` (PowerGetActiveScheme/PowerSetActiveScheme P/Invoke), `RestorePoint.Create(description)` (SRSetRestorePointW P/Invoke), `WindowsEnvironment` (env genişletme, sürücü listesi). CI Windows işinde gerçek kayıt defterinde HKCU\Software\BoostRoot.Tests altında gidiş-dönüş testi.
