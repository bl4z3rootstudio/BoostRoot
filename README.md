## Türkçe

### Ne yapar?
1. **Oyununu seç, Boost'a bas.** BoostRoot o oyunun ayar dosyasını, Windows'u ve ekran kartını oyuna göre ayarlar.
2. **"Oyunu başlatayım mı?"** — Evet dersen oyunu açar, "Hayır, ben açarım" dersen bekler.
3. **Beğenmedin mi?** "Geri al" — her değişiklik kayıtlıdır, tek tıkla eski haline döner.

### Üç söz
- ✅ **Çözünürlüğüne, tuşlarına, hassasiyetine ve nişangâhına asla dokunmaz.** (4:3 Stretched yalnızca sen o oyun için açarsan.)
- ✅ **Her değişiklik geri alınabilir.** İlk Boost'tan önce Windows geri yükleme noktası da oluşturur. Kaldırırken "her şeyi geri al" seçeneği vardır.
- ✅ **Oyuna hiçbir şey enjekte etmez.** Sadece ayar dosyalarını düzenler; gösterge ve nişangâh ayrı, tıklanamaz pencerelerdir. Vanguard, EAC, BattlEye ile güvenle çalışır.

### Kurulum
[Son sürümü indir](https://github.com/bl4z3rootstudio/BoostRoot/releases/latest) → `BoostRoot-Setup-xx.x.x.exe`.
Windows SmartScreen "tanınmayan uygulama" diyebilir (kod imzalama sertifikası ücretli olduğu için yok): **Ek bilgi → Yine de çalıştır**. Dosyanın SHA-256 değerini sürümdeki `SHA256SUMS.txt` ile karşılaştırabilirsin.

### Sık sorulanlar
- **Ban yer miyim?** Hayır. BoostRoot oyunun belleğine/sürecine dokunmaz; sadece oyunun kendi ayar dosyasını oyun kapalıyken düzenler — bunu sen oyun içinden de yapabilirsin.
- **İnternet ayarlarımı değiştirir mi?** Hayır. DNS, TCP, ağ kartı ayarlarına dokunmaz; sadece ölçer ve önerir.
- **Antivirüs uyarısı?** Uygulama yönetici izni ister (Windows ayarları için). Kaynak kod açık; kendin derleyebilirsin.

## English

**Pick a game, press Boost.** BoostRoot tunes that game's settings file, Windows and your graphics driver — and asks "Launch the game now?".
Everything is journaled and can be undone with one click. It **never** touches your resolution, keybinds, sensitivity or crosshair, and **never injects** anything into games (safe with Vanguard / EAC / BattlEye).

Features: 500+ games (30 with file-level tuning, any installed game gets a generic boost) · Crosshair Studio (export to VALORANT code / CS2 commands / overlay) · RAM cleaner · playtime tracking · 4 levels with a recommendation for your PC · PC report card · FPS test with before/after share images · CPU/GPU/RAM stress tests with live charts and safety cut-offs · network analysis · junk cleaner, startup manager, driver check · in-game overlay (Alt+O) · crosshair (Alt+C) · clips (Alt+F10 / Alt+F9 / Alt+F1) with trim, vertical crop and Discord upload · optional per-game 4:3 stretched · auto-update with SHA-256 verification. AMD and NVIDIA, Windows 10/11.

## Geliştirme / Development
```bash
dotnet test                     # 190+ tests (Linux or Windows)
dotnet run --project src/BoostRoot.App   # Windows
```
- `src/BoostRoot.Core` — safety (NeverTouchGuard, journal, undo), config formats, profiles, FPS/stress/clip logic (cross-platform, tested)
- `src/BoostRoot.Platform.Windows` — registry, processes, sensors (NVML/ADL), WASAPI, hotkeys, display
- `src/BoostRoot.ViewModels` / `src/BoostRoot.App` — Avalonia UI (NativeAOT)
- `profiles/*.json` — game profiles ([format](docs/profiles.md)); generator: `tools/gen-profiles.py`

Release: push a tag `v26.11.1` → GitHub Actions builds the installer, portable zip and `SHA256SUMS.txt`.
